# Nylah Studios v0.3.0 — Visual Treatment Pass

## Why this exists (the user's words)

RedSilk (the CouchHub launcher) is beautiful — curated images, glows,
elegance. The TV app feels "depressing and vibevody" and "miles away
from RedSilk". The app has far more areas, nooks and crannies than
RedSilk ever did — RedSilk was a dashboard, four tiles and settings;
this app has dozens of screens. It needs ~15x the pass RedSilk got.

Scope correction from the user (2026-11-10 01:00): **LESS an overhaul.
The skeleton is there.** This is a visual treatment pass only. Layout,
navigation, behavior, data — all unchanged. Same skeleton, RedSilk-grade
surfaces. If a surface cannot be graded without a layout change, leave
it and say so — do not force it.

## The shared visual language (one language, every worker)

Reference: the launcher at `~/workspace/couchhub` — `ThemeRedSilk.xaml`
and README. RedSilk = deep wine burgundy `#1E0F13`, accent `#C14B5F`,
beige `#F6EEE3`, Georgia serif display, burgundy silk photograph behind
ivory text. Translate that look; do not copy its code.

### Tokens (W5 owns `src/styles/global.css` — nobody else edits tokens)

Existing `--nylah-*` tokens (v0.2.0) stay; W5 extends them. New tokens:

```css
--nylah-font-display: "Instrument Serif", Georgia, "Times New Roman", serif;
--nylah-wine:        oklch(0.45 0.19 350);   /* accent wine (exists) */
--nylah-wine-deep:   oklch(0.155 0.045 350); /* page bg dark (exists) */
--nylah-wine-bright: oklch(0.72 0.17 350);   /* accent bright (exists) */
--nylah-gold:        oklch(0.85 0.16 90);    /* brass/gold (exists) */
--nylah-beige:       oklch(0.93 0.028 75);   /* warm beige light (exists) */
--nylah-cream:       oklch(0.97 0.014 75);   /* warm cream light (exists) */
--nylah-surface-warm:   light-dark(oklch(0.97 0.014 75), oklch(0.21 0.045 350));
--nylah-surface-2-warm: light-dark(oklch(0.89 0.032 75), oklch(0.26 0.05 350));
--nylah-card-shadow: 0 10px 36px oklch(0.10 0.05 350 / 0.45);
--nylah-card-shadow-lift: 0 18px 48px oklch(0.10 0.05 350 / 0.55);
--nylah-focus-glow-strong: 0 0 32px 4px var(--nylah-focus-glow);
```

### Rules (every worker, no exceptions)

1. **Consume tokens only** as `var(--nylah-<name>, <fallback>)`. Never
   hardcode a hex/oklch value in a component. Grep your files for
   `#[0-9a-fA-F]{3,8}` and `oklch(` and replace.
2. **Warmth:** dark surfaces are wine hue 350, chroma ≥ 0.04. No
   hue-255 slate visible anywhere. Light theme stays warm beige hue 75.
   (The burgundy accent preset already re-tints the base surfaces; the
   gap is components that never consume them.)
3. **Typography:** Instrument Serif for hero, rail titles, dialog
   titles, section headings. Legible at 3 m. UI/body text stays sans.
4. **Depth + glow:** layered shadows, soft ambient glow behind focused
   cards, strong wine focus glow — focused things feel *lit*, not
   outlined. Flat fills become warm gradients.
5. **Cards:** warm tinted bg, 1px soft line, radius `1rem`, layered
   shadow; focused card lifts + halo.
6. **Curated art (the user's word — NOT "custard"):** original
   atmospheric art only, where the app owns the surface (home hero
   backdrop, login, profile picker, empty states, search landing).
   RedSilk burgundy/warm palette, cinematic. Never the launcher's tile
   images verbatim, never copyrighted or stock-looking imagery. Poster
   cards keep provider art; the frame/chrome/atmosphere is ours.
7. **States:** every surface graded in all its states — loading,
   empty, error, focused, selected. An empty state is a surface too.
